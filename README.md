# Portfolio Website - Aditiya Pratama (React + Vite)

Portofolio pribadi interaktif **Aditiya Pratama** (Mahasiswa Informatika, UI/UX Designer, & AI Enthusiast) yang dibangun dengan **React.js** dan dibundel menggunakan **Vite**.

## 🚀 Fitur Unggulan

- **Cyber Cosmic Preloader / Splash Screen**: Animasi loading sistem futuristik dengan progress bar, status stages, dan tombol *Skip Intro*.
- **Interactive Space Canvas**: Efek partikel konstelasi bintang interaktif yang merespons pergerakan kursor mouse.
- **Custom Glowing Space Cursor**: Efek kursor neon halus dengan animasi follower dan scale effect pada elemen interaktif.
- **Bilingual i18n Support**: Dukungan pergantian bahasa instan (Bahasa Indonesia 🇮🇩 & English 🇬🇧) yang tersimpan di `localStorage`.
- **Typing Hero Effect**: Animasi mengetik dinamis untuk peran keahlian pada section hero.
- **Interactive Stats & Skills Progress**: Counter statistik dan bar progress keahlian yang teranimasi otomatis saat di-scroll ke viewport.
- **Interactive Project Showcase**: Filter kategori proyek (Web & POS, Mobile & SIG, UI/UX & Game, AI & Vision) dengan efek kartu 3D tilt hover dan modal detail lightbox.
- **Featured Live Demo**: Integrasi langsung dengan portal destinasi *Explore Pesisir Barat*.
- **Achievement & Certificate Lightbox**: Tampilan sertifikat juara dan penghargaan dengan modal zoom gambar.
- **Astronaut Space Companion**: Maskot astronot interaktif yang berpatroli mengambang di layar, bereaksi terhadap arah scroll, memunculkan quote balon dialog, dan memiliki fungsi *smooth scroll to top*.

## 🛠️ Menjalankan Proyek Secara Lokal

### 1. Instalasi Dependensi
```bash
npm install
```

### 2. Menjalankan Server Pengembangan (Dev)
```bash
npm run dev
```
Buka URL lokal yang muncul (biasanya [http://localhost:5173](http://localhost:5173)) di browser Anda.

### 3. Build untuk Produksi
```bash
npm run build
```
Hasil build produksi siap di-deploy akan berada di folder `dist/`.

### 4. Menjalankan Preview Hasil Build
```bash
npm run preview
```
